# GAZARRA — Agentes Reconstruídos v2
Data: 07/09/2026. Status: HOMOLOGAÇÃO, não produção.

Este segundo lote contém 11 agentes, governança, calculadora paramétrica e testes. Reconstruído a partir de 10 arquivos originais do pacote adquirido. O agente INSS/FGTS foi separado em dois módulos para reduzir acoplamento e erros de incidência.

## Instalação e uso
Leia a governança antes de qualquer agente. Os arquivos Markdown podem servir como instruções de agentes no Claude Code ou como procedimentos adaptados ao ChatGPT. A instalação em Claude Code exige verificar a documentação oficial da versão instalada; este pacote não executa instalador, não concede acesso ao ERP e não configura integrações.
Não substituir automaticamente os agentes comprados. Manter os originais como backup e testar esta versão em ambiente isolado, com dados fictícios.
A calculadora é um exemplo técnico independente e não contém tabelas legais. Não é motor de folha homologado.

## Homologação
1. Revisão jurídica/tributária por competência e categoria.
2. Carga de parâmetros oficiais com vigência e fonte.
3. Testes com casos reais anonimizados e resultados conferidos no ERP.
4. Conciliação eSocial, EFD-Reinf, DCTFWeb e FGTS Digital.
5. Aprovação do responsável técnico e controle de versões.
6. Integração somente leitura inicialmente; qualquer escrita exige autorização específica.

## Limitações
Não foram executados testes de integração com ERP, portais governamentais ou transmissão. Os testes automatizados cobrem apenas a calculadora ilustrativa. Nenhuma tabela legal foi certificada como motor de produção.
