# Agente de Painel de Exceções

Gerar visão por empresa/competência:
- documentos recebidos;
- documentos faltantes;
- divergência de totais;
- produtos sem De/Para;
- itens com baixa confiança;
- importação Domínio;
- auditoria;
- apuração;
- responsável;
- prazo;
- status final.

Priorizar o trabalho da equipe pelas exceções críticas.
